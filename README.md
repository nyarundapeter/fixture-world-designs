# Fixture World Designs: interior design portfolios

Static site with two portfolios built from the designer's own project PDFs.

- `index.html`: landing page linking to both
- `business.html`: client-facing portfolio (Fixture World Designs)
- `technical.html`: technical folio for design studios, laid out as a sheet set
- `assets/`: renders and drawings taken from the original portfolios

No build step. Open `index.html` locally or serve the folder with any static host (GitHub Pages is used here).
